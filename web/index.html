演示导览

  1. A 普通退货退款客户 → 仓库 → 客户

    示例诉求“退 1 根数据线”：确认方案、提交申请、寄回，仓库签收检验后模拟退款 33.33 元。

  2. B 质量问题审批客户 → 客服 → 仓库

    “质量问题退耳机”：方案需客服审批，批准后按 A 寄回检验，退款 699 元。

  3. C 退款超时核对客户 → 客服演示控制

    “退鼠标”走到待退款，客服把退款设为“成功但响应超时”；客户核对原结果，不会重复退款。

  4. D 同款换货客户 → 仓库

    “同款换货”：键盘白换黑，确认时预留库存，仓库签收、检验、换新发货与送达。

  5. E 政策咨询与拒答客户

    “咨询退货期限”给出引用条款；“以旧换新”是政策未覆盖的问题，应说明限制并转人工。

  6. F 物流与人工工单客户 → 客服

    “查询物流”看延迟件，“转人工”生成工单，客服在待办中回复。

客户页输入框上方的示例诉求按钮对应以上场景；完整步骤见测试指南。
